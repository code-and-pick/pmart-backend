# ADR-0070 화면 번호 규칙 — 사람이 보는 번호와 시스템 ID 를 나눈다

- 상태: 승인 (2026-11-18, 사용자)
- 근거(사용자 2026-11-18): "DLV-83649921-c0e3-… 이게 정확히 뭘 의미하는 번호인지 알 수 있어야 하지 않을까", "주문 100개면 뭐가 뭔지 저 긴걸 다 언제 확인해", "다른 쪽 시뮬레이션도 이렇게 직관적으로 보이게 다같이 적용되는 규칙을 정해야", "안에 들어가면 상세번호가 나오게" → 배송 "주문번호-순번", 라이더 "라이더 번호 6자리 + 가린 이름".
- 관련: 화면용 주문번호 8자리(2026-11-16 `docs/handoff/clients/all/2026-11-16-reply-display-order-number.md`), 포장 라벨 숫자 6자리(mfc-fulfillment F-5).

## 결정
1. **시스템 ID 는 그대로** 둔다(`ORD-…`·`DLV-…`·`RD-…` UUID — 서비스 사이 열쇠, 계약·이벤트·DB 키). 화면에 보일 **화면 번호를 따로** 둔다.
2. 화면 번호:

| 대상 | 화면 번호 | 예 | 정하는 곳 |
|---|---|---|---|
| 주문 | 숫자 8자리(무작위, 겹치지 않음) | `74939255` | order(있음) |
| 배송 | **화면용 주문번호-순번**(같은 주문의 몇 번째 배송, 1부터) | `74939255-1` 첫 배송, `74939255-2` 반납·회수·재발송 | dispatch 순번(`delivery_seq`, `DeliveryCreated.deliverySeq`) → execution·dispatch 응답 `deliveryNumber` |
| 라이더 | **숫자 6자리**(무작위, 겹치지 않음, 바뀌지 않음) + 가린 이름 | `김*수 · 482913` | rider(`riderNumber`, 가입 때) |
| 포장 | 라벨 숫자 6자리 | `305118` | mfc-fulfillment(있음) |

3. **화면 규칙(모든 웹·앱·시뮬레이터 공통)**
   - 목록·표·지도·알림·대화에는 **화면 번호만**. 시스템 ID 를 목록에 내지 않는다.
   - 배송은 화면 번호 옆에 **종류 표시**(배송·재발송·다시 배송·반납·회수)를 붙인다 — 순번만으로는 무슨 배송인지 모른다.
   - 라이더는 **가린 이름 + 라이더 번호**. Google 계정(이메일)은 로그인 수단이라 화면에 내지 않는다. 전화번호는 상세에서만, 가린 값.
   - **상세 화면 안에 "시스템 번호" 칸**(접어 두고 복사 버튼) — 서버 로그·문의 대조용.
   - 찾기는 화면 번호로 된다(주문번호 — 배송 찾기 `orderNumber`, 라이더 번호 — `GET /riders?riderNumber=`). 배송 번호 `74939255-2` 로 찾으려면 앞 8자리로 주문을 찾고 순번으로 고른다.
   - 화면 번호를 아직 모르면(주문 확정 전, 옛 기록) 시스템 ID 끝 8자리를 회색으로 보이고 "번호 없음" 표시.
4. 순번은 dispatch 가 배송을 만들 때 주문마다 늘린다(DB 트리거 — 주문마다 잠금). 예전 배송은 생성순으로 채웠다(dispatch V13). 같은 주문의 회수·반납·재발송·다시 배송이 2, 3, … 이 된다.

## 결과
- 백엔드(PC 5, 2026-11-18): rider 0.12.0(V10 `rider_number`, 직원 목록·상세·찾기 `riderNumber`·`riderIds`, 본인 프로필, 운행 중 목록), tracking 0.10.0(관제 `riderNumber`), dispatch 0.10.0(V13 `delivery_seq`, `DeliveryCreated.deliverySeq`, 배정 이력 `deliveryNumber`), execution 0.26.0(V19, 배송 조회·직원 목록·내 배달 내역 `deliveryNumber`).
- 아직: 다른 응답에 라이더 번호를 직접 싣지는 않았다 — 배송 목록 등 `riderId` 만 있는 화면은 `GET /riders?riderIds=a,b,c`(50개)로 한 번에 붙인다. 관제 진행 중 배송에는 배송 번호가 없다(배송 상세에서).
