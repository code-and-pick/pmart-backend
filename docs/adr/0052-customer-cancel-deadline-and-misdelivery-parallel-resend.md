# ADR-0052 고객 자율 취소는 상품준비 전까지, 확인된 오배송은 회수와 새 발송을 동시에

- 상태: 승인, **결정 2 는 ADR-0060 으로 대체**(2026-11-13 — 상품준비 뒤 고객센터 취소 없음) (2026-11-09, 사용자 — 취소: "취소는 피킹 전(주문의 상품준비 상태 전)까지 가능하도록, 주문 내역상으로도 가능"; 오배송: "인근 다른 라이더가 재배차되어 오배송지 방문 후 MFC 로 회수 ➔ 원래 주소로 배송, 고객만족을 위해 둘이 동시에" → Claude 추천안(회수와 새 발송 병행, 오배송 확인 때만 자동, 재고 부족은 그 품목 부분 환불, 상품준비 뒤 취소는 고객센터 접수) "그대로 하면 될것같아")
- 대체: 업무 원문 OMS §8.3 "정확한 고객 자율 취소 마감과 CS 승인선은 팀 확정이 필요" 를 정한다. OMS §9 "재배송은 교환 승인 건에 한해 허용" 에 **확인된 오배송의 새 발송** 예외를 더한다. Commerce §13.2 "라이더 연락만으로 환불을 승인하지 않는다" 는 그대로 — 자동 처리는 아래 확인 조건을 만족할 때만.
- 관련: `contracts/states/order-states.md`, `docs/business/flows/cancel-vs-handover.md`, ADR-0046(피킹 뒤 취소 복귀), ADR-0049(결품 부분 취소), `docs/architecture/service-requests/delivery-dispatch-service.md` DD-1

## 배경
- 고객 자율 취소 마감이 정해지지 않아 상담 문서·고객 안내가 "확인 중" 으로만 남아 있었다.
- 오배송은 원래 라이더가 이미 다른 코스로 이동했을 가능성이 높다. 회수한 상품을 MFC 로 가져와 다시 보내면 고객이 오래 기다리고, 다른 집에 갔던 상품(보냉 깨짐·개봉 가능)을 받게 된다. 신선·냉장·냉동 회수품은 다시 팔지 않는다(확정 정책, OMS §11.2).

## 결정
1. **고객 자율 취소**: 주문이 `PREPARING`(상품준비 — 현장 준비 시작 확정)이 되기 전까지 고객이 앱 주문 내역에서 스스로 취소할 수 있다. 취소 요청은 지금처럼 접수 → 출고 중지 확인 → 결제 취소 결과로 완료된다(OMS §8.4 그대로).
2. ~~**상품준비 뒤 취소**: 고객 앱에서는 할 수 없다.~~ → **ADR-0060**: 상품준비 뒤 ~ 인계 전 고객 요청 취소는 고객센터로도 받지 않는다(인계 뒤 회수 D-7 은 그대로). 옛 문구: 고객센터 문의로 접수하고, MFC 출고 중지가 확인된 미인계 수량만 취소한다. 인계된 수량은 회수·반품(지금 규칙 그대로).
3. **오배송 확인 조건**: 아래 중 하나가 있을 때만 자동으로 처리한다. 고객 진술만이면 고객센터 문의 접수로 넘겨 사람이 판단한다.
   - 라이더가 다른 곳에 전달했다고 확인
   - 배송 완료 사진의 위치가 주문 주소와 다름
   - 잘못 받은 사람이 연락함
4. **동시 처리**: 오배송이 확인되면 두 일을 **함께** 시작한다.
   - **새 발송**: MFC 가 같은 상품·수량을 다시 확보·피킹·포장해 원래 주소로 보낸다(구매자 비용 0원). 재고가 모자란 품목은 그 품목만 부분 취소·환불(ADR-0049 와 같은 방식, 대체 상품 없음).
   - **회수**: 인근 다른 라이더를 자동 배차해 오배송지에서 회수하고 MFC 로 반납한다. 신선·냉장·냉동은 폐기, 상온 미개봉품만 검수 후 재고 복구.
   - 회수한 상품을 원래 고객에게 다시 보내지 않는다.
5. 같은 피해 수량을 새 발송과 환불로 겹쳐 처리하지 않는다.

## 적용 시점
- 1·2 는 order-service·orchestration·고객앱 취소 버튼에 반영한다(구현 별도 — 지금 취소 가능 판정과 대조 필요).
- 3·4 는 라이더 자동 배차가 필요해 **delivery-dispatch(DD-1) 구현 뒤**에 넣는다. 그 전에는 상담원이 고객센터 문의로 접수하고 같은 원칙(새 발송 + 회수)으로 처리한다.

## 남은 것
- 오배송 새 발송이 늦어질 때(재고 확보·라이더 배정 실패)의 기한과 고객 안내.
- 오배송 확인을 누가 기록하는가(라이더 앱·관제·상담원)와 사진 위치 판정 방법.
- 라이더 귀책 비용(배달료 미지급 등)은 지금 규칙(Delivery §9.3) 그대로 — 상담·자동 처리와 분리.

## 결과
- 고객: 취소 가능 시점이 분명해지고, 오배송 때 회수를 기다리지 않고 새 상품을 받는다.
- 운영: 오배송 1건에 재고가 한 번 더 나가고 라이더가 두 번 움직인다(회수·새 배송). 확인 조건으로 악용을 줄인다.
