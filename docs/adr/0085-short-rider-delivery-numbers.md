# ADR-0085 짧은 화면 번호 — 라이더 `R4785`, 배송 `D74939255`

- 상태: **승인** (2026-11-22, 사용자)
- 대체: ADR-0070 결정 2 표의 **배송·라이더 줄**(나머지 — 시스템 ID 와 화면 번호를 나누는 원칙, 주문·포장·직원·접수·고객 표기, 화면 규칙은 그대로)
- 근거(사용자 2026-11-22): "라이더 구분번호 이름* 번호여섯자리인데 너무 길고 별로야. 배송번호도 8자리-3 이런데 … 배송 D2876 라이더 R4785 좀 이렇게 간단하게" → 고른 안: 배송 "D28767701 이렇게 주문번호 재사용하는데 구분 가게 앞에 D 붙이자", 라이더 "R4785 만"(목록에 가린 이름 없이).

## 결정
1. **라이더 = `R` + 숫자 4자리**(`R4785`). 무작위·겹치지 않음·바뀌지 않음. 4자리가 거의 다 차서 50번 뽑아도 빈 번호가 없으면 5자리(`R48251`). rider-service V14 가 **기존 라이더 번호(6자리)를 모두 새 번호로 바꾼다** — 다른 서비스는 번호 사본을 두지 않고 rider 조회로 읽는다(tracking 관제·backoffice-bff 표기).
2. **목록·표·지도에는 라이더 번호만** 보인다. 가린 이름은 마우스를 올리면(title)·상세에서. (ADR-0070 의 "가린 이름 · 번호"를 바꿈.)
3. **배송 = `D` + 화면용 주문번호 8자리**(`D74939255`). 같은 주문의 두 번째 배송부터(회수·반납·재발송·다시 배송) `-순번`(`D74939255-2`). 순번은 그대로 dispatch `delivery_seq`. `D` 는 주문번호(`74939255`)와 배송을 눈으로 구분하려고 붙인다. 종류 표시(배송·반납·회수…)는 계속 번호 옆에.
4. **찾기**: 라이더 번호는 `R4785`·`r4785`·`4785` 를 같은 번호로(rider `GET /riders?riderNumber=`, 탈퇴 목록). 배송은 화면이 `D` 와 `-순번` 을 떼고 주문번호 8자리로 찾는다(execution `orderNumber` 는 그대로 숫자 8자리).
5. 번호를 아직 모르면(옛 기록) ADR-0070 규칙 그대로.

- 화면(각 세션): 라이더 표기에서 가린 이름을 목록에서 빼기, 찾기 칸 정규식(`^\d{6}$` → `R?\d{4,5}`, `^\d{8}-\d+$` → `D?\d{8}(-\d+)?`), 시험 값. 알림 `docs/handoff/clients/all/2026-11-22-notice-short-display-numbers.md`·`docs/handoff/simulator/2026-11-22-notice-short-display-numbers.md`.
