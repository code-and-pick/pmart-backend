# 주문·클레임 사내 정책 문서 — RAG 원고 (초안)

고객센터 상담원·운영 관리자·센터 관리자·지원센터(라이더 운영) 등 직원이 주문, 결제 금액, 취소, 결품, 환불, 반품·교환, 오배송, 배송 문제 상담에 관해 백오피스 정책 질문(운영자용 RAG)으로 찾아볼 **직원용 사내 정책 문서** 초안입니다. 고객에게 공개하는 문서가 아닙니다(고객용 안내는 `customer_app/`). 상담 접수·접수 건 처리는 `backoffice/05-customer-center-cases.md`, MFC 현장 처리는 `mfc/`, 배송 쪽 처리(배차·전달 실패·회수 배송·사고 재발송·라이더 수행료)는 `delivery/` 에 있으며 여기서는 다시 적지 않고 참조만 합니다.

## 색인에 넣으려면 (아직 안 함)
- 운영자용 RAG 색인 대상 후보 — 넣을지는 사용자 결정, 승인 뒤.

## 넣지 않은 것
- **정하지 않은 것**: 환불이 카드·계좌에 반영되는 기간 안내 문구, 지연 보상 기준·장기 지연 기준, 회수 없이 처리할 소액·신선 기준, 사진 제출 방법, 문자·알림톡 채널, 취소 사유 코드 목록, 교환 승인 뒤 철회 범위·비용·거절품 재전달, 일반 교환·반품 증빙 기준, 수령 후 전품 반품의 첫 구매 복원, 오배송 새 발송 지연 기한·안내, 단일 10kg 초과 외 분할 세부값, 예약 시간대 정원 값.
- **쿠폰 중 정하지 않은 것**: 부분 반품 때 쿠폰 할인 환수, 쿠폰 남용 제한(ADR-0082 남은 정책), 배차 불가 보상 쿠폰(ADR-0082 5단계 — 아직 없음). 08 제3조 5항(지연 쿠폰 보상 없음)은 지연 보상 기준이 정해지지 않아 그대로 둠. 오배송 환불의 상품값에 할인 몫을 빼는지는 구현 근거를 찾지 못해 05 표의 오배송 줄은 고치지 않음.
- **바뀐 규칙**: 결품 사전 선택별 처리·고객센터 이관(ADR-0049 로 바뀜), 상품준비 뒤 고객센터 미인계분 취소(ADR-0060 으로 바뀜), 확인된 오배송은 늘 회수 + 새 발송(ADR-0065 로 바뀜).
- **상담 대본·문구**: cs-scripts 의 대본·첫 인사는 운영 승인 전이라 넣지 않음. 본인 확인 원칙·문의 종류별 본인 확인 표·주문 확인 문구(`cs-scripts/01` §1·§2·§4)는 2026-11-28 사용자 승인 뒤 `backoffice/05` 제15조에 넣음.
- **다른 문서 몫**: 결품 보고·재확보·관리자 부분 종료·관리자 판단 취소 절차(`mfc/`), 배차 불가 자동 취소 조건·배차 지연 알림·사고 재발송 수량·회수 배송 운영·라이더 수행료(`delivery/`), 상담 본인 확인 방법·접수 건 담당 팀·처리 기한(`backoffice/05`), 탈퇴 중 주문(`customer_app/02`).

## 확인 필요
1. **반품 접수 기한 검사**: 업무 원문은 수령 후 7일·신선 24시간 접수 기한을 정했지만, 고객센터 반품 접수는 지금 시스템이 기한을 검사하지 않고 상담원이 판단한다(CL-1 추가 결정 7). 본문 06 제2조 7항으로 적음.
2. **교환**: 기한·비용은 업무 원문 결정이지만 교환 접수·재배송 기능은 아직 없다(claim 501). 본문에는 결정된 기한·비용·원칙만 적었다 — 교환을 지금 받을 수 있는지 상담원 안내 방식 확인 필요.
3. ~~**반품 신청 경로**~~ — 해결(사용자 결정 2026-11-20: 구현을 따름): 고객 앱 반품·교환 신청은 막고 고객센터가 접수. `customer_app/13` 제4조를 "고객센터 문의로 신청, 본인 확인 뒤 접수, 전달 완료 뒤에만"으로 맞춤. 같은 김에 본문 06 제3조 2·4항을 구현(claim `ReturnRules` — 전달 완료 수량 deliveredQty, 2026-11-17 사용자 "배달 중이나 전달 완료 전에는 반품 불가")대로 "인계 수량" → "전달 완료 수량"으로 고침.
4. ~~**단순 변심 반품 회수비**~~ — 해결(사용자 결정 2026-11-20: 2026-11-17 CL-1 결정을 따름): 회사 잘못이 아니면 9,000원 고객 부담. 본문 06 제4조 그대로, `customer_app/13` 제3조에 같은 뜻으로 넣음(고객 문서에서는 고객에게 맞지 않는 "잘못된 대체 상품" 면제 사유는 뺌 — 고객에게는 대체 상품이 없다고 안내함).
5. ~~**전체 결품 → 전체 취소**~~ — 해결(사용자 결정 2026-11-20: 주문 쪽에 맞춤): 본문 04 제3조 4항이 정본. `mfc/04` 제4조 5·6항과 `mfc/06` 제5조 6항이 이를 가리키도록 고침, `mfc/README.md` 확인 필요 1 해결.
