# 회신 — 한집배달은 혼자만 (dispatch)

보낸 영역: delivery
- 작성: pmart-backend PC 5(delivery), 2026-11-18
- 대상: pmart-clients `apps/rider_app` — 요청 `docs/handoff/rider-app/2026-11-18-backend-single-delivery-exclusive.md`(PR #150)
- 상태: **이미 구현·LAN 배포됨**(백엔드 PR #190 — 사용자 2026-11-18 "한집은 단독", ADR-0058 덧붙임)

## 지금 서버 판정
1. **한집(deliveryMode SINGLE, 회수·반납 아님)을 맡은 라이더**: AI 추천 후보에서 빠지고(새 제안 없음), 배달리스트는 빈 목록, 제안·목록 수락은 `LATE`·`INELIGIBLE`.
   - 다만 `GET /offers` 의 `pollAfterSec` 는 null 이 아니다(신규배차 켬이면 그대로) — 앱이 폴링해도 제안이 오지 않을 뿐. 필요하면 null 로 바꿀 수 있음(요청 주세요).
2. **다른 배송을 맡고 있으면** 한집은 후보에서 빠지고(배달리스트에도 안 보임), 수락하면 `INELIGIBLE`.
3. 알뜰(BUNDLED)은 지금처럼 최대 3건(하나씩 배달 ON 이면 1건).
4. 예약·회수:
   - **예약(SCHEDULED)**: 한집으로 치지 않는다 — 알뜰과 같은 한도(3건) 안에서 함께 맡을 수 있다. 묶음 제안은 하지 않는다(한 건씩 제안).
   - **회수·반납(type RETURN — 오배송 회수·반품 회수·전달 실패 반납)**: 한집으로 치지 않는다 — 한집을 든 라이더도 반납 배송을 받는다(전달 실패 반납은 같은 라이더에게 바로 배정).
   - 예약을 한집처럼 단독으로 할지는 업무 결정 — 사용자에게 물어 주세요(정해지면 바로 바꿈).
