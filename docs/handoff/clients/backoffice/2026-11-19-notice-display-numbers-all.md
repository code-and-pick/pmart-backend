## 공통 규칙(모든 화면)
- **목록·표·링크 글자에는 화면 표기만** — `CLM-…`·`AP-…`·`OP-…`·`CASE-…` 같은 시스템 ID 도, "ID 끝 8자리 회색"도 쓰지 않는다.
- **상세에는 "시스템 번호" 칸 + 복사 버튼**(지금처럼).
- 찾기 칸은 화면 표기로 — 시스템 ID 를 붙여 넣어도 찾게 둔다.
- 표기를 아직 못 받는 대상(옛 데이터·원천 미배포)은 **종류 · 시각**.
