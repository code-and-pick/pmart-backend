# [pmart-backend → pmart-clients] 공지: 백오피스 정책 질문(운영자 RAG) LAN 배포·생성 답변 (2026-11-09)

- 성격: **공지(백오피스, 선택 구현).** 2026-11-04 안내(`../backoffice/2026-11-04-clients-request-ai-assistant.md`)의 API 그대로다 — 계약 변경 없음.
- 결정: ADR-0051(운영자용·고객용 분리, LAN Ollama). 이 API 는 **운영자 전용**이다. 고객앱 질문은 별도 서비스(`customer-assistant-service`, 아직 없음)로 나중에 안내한다.

## 바뀐 것
- **LAN 에 배포됐다**: 게이트웨이 `http://192.168.0.40:8080/api/v1/assistant/**`(운영자 토큰, `X-Source-System: backoffice-web`, 질문은 `Idempotency-Key` 필수 — 11-04 안내 그대로).
- **답이 문서 발췌가 아니라 생성 문장이다**: 응답 `answerMode=GENERATIVE`, `retrievalMode=SEMANTIC`. 인용 검사에 실패하면 예전처럼 발췌(`BASELINE_EXTRACTIVE`)로 바뀌고, 근거가 없으면 `NONE`. "기준선(문서 발췌)" 표시는 `answerMode` 를 보고 붙여 주면 좋다.
- 응답 시간: 2026-11-09 확인 2~4초. 서버 재시작 직후 첫 질문은 모델을 올리느라 실패(503)할 수 있다 — 잠시 뒤 같은 `Idempotency-Key` 로 다시 보내면 된다.

## 화면에서 알려 주면 좋은 것
- 근거(인용) 목록을 답과 함께 보여 준다 — 확인 결과 답이 질문과 다른 주제를 근거로 한 경우가 있었다(아래). "근거를 꼭 확인하세요" 안내 권장.
- 실시간 조회(특정 주문·재고 상태)는 답하지 않고 업무 화면을 안내한다(`answerMode=NONE`).

## 확인한 질문(LAN, 6개)
결품 처리(ADR-0049 근거로 정답), 봉투값 환불(정답), 서비스 간 인증(정답 "아니요" — 짧음), 근거 없는 질문(NONE), 실시간 질문(NONE) — 그리고 "배정 추천의 목표 순서"는 **피킹 방문 순서로 잘못 답했다**(근거는 인용했으나 주제가 다름). 답변 품질 평가는 계속한다.
