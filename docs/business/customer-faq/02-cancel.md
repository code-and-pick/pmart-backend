# 주문 취소

## 주문을 취소하고 싶어요 [확정 정책]

- 주문이 **상품 준비를 시작하기 전까지** 앱의 **주문 내역**에서 직접 취소할 수 있어요.
- 상품 준비가 시작된 뒤에는 취소할 수 없어요(앱·고객센터 모두). 받으신 뒤 **반품**으로 도와드려요([08](08-return-exchange.md)).
- 이미 라이더에게 전달돼 출발한 상품은 주문 취소 대신, 받으신 뒤 **반품**으로 도와드려요([08](08-return-exchange.md)).

## 취소 버튼을 눌렀는데 바로 취소 완료가 아니에요 [채택 설계]

- 취소 버튼은 **취소 요청**이에요. 센터에서 상품 준비를 멈추고 결제 취소가 끝나야 **취소 완료**가 돼요.
- 진행 단계는 주문 상세에서 볼 수 있어요: 취소 요청 → 확인 중 → 취소 처리 중 → 취소 완료(또는 취소 불가).
- 결과는 앱 알림으로 알려 드려요. 확인 중일 때 다시 누르지 않으셔도 돼요(같은 요청으로 이어져요).

## 상품 준비가 시작된 뒤 취소 문의를 하면요? [확정 정책]

- 상품 준비가 시작된 주문은 고객센터에서도 취소해 드릴 수 없어요. 상품을 받으신 뒤 **반품**으로 도와드려요([08](08-return-exchange.md)).
- 센터에 상품이 없어 일부를 보낼 수 없을 때는 그 상품만 자동으로 취소·환불되고 앱 알림으로 알려 드려요.

## 취소하면 봉투값도 돌려받나요? [확정 정책]

- **주문 전체를 취소하면** 결제 금액과 함께 **봉투값(100원)도 환불**돼요.
- 결품 등으로 **일부만 취소**되면 봉투값은 환불되지 않아요.

## 결제가 아직 확인 중이에요 [채택 설계]

- 결제 결과를 확인하는 동안에는 다시 결제하지 마세요. 결과가 나오면 앱 알림으로 알려 드려요.

## 취소 후 다시 주문하고 싶어요 [설계안]

- 새 주문으로 진행돼요. 이전 주문의 요청 사항은 넘어가지 않으니 새로 적어 주세요.
- 이전 주문의 취소·환불은 새 주문과 따로 진행돼요.
